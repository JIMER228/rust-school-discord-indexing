== Installation ==

RealPVE:
	Before installing the RealPVE plugin, make sure you have copied all the necessary images for it to function from the archive("data" folder) to your server "*SERVER*\oxide".
	Then simply copy the RealPVE.cs file into the "*SERVER*\oxide\plugins\" directory.
	
*Optional - RaidableBases settings(bonus):
	To install settings for the RaidableBases plugin, you need to copy all files from the Bonus folder into the "*SERVER*\oxide\" directory, replacing any existing files.
	Reload the RaidableBases plugin using the command "o.reload RaidableBases" or "c.reload RaidableBases" if you are using Carbon.

Note: The settings are tailored for a x1 PvE servers and for the paid version of the RaidableBases plugin( https://codefling.com/plugins/raidable-bases ).
It is recommended to check all configurations for the RaidableBases plugin, especially the loot configuration.
