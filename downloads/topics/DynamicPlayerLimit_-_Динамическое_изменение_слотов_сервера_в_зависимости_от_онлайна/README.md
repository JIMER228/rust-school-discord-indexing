DynamicPlayerLimit - Динамическое изменение слотов сервера в зависимости от онлайна

Конфигурация:

Плагин использует конфигурационный файл для установки параметров, таких как MaxPlayers, MinPlayers, IncreaseThreshold, DecreaseThreshold и UpdateInterval.
Эти параметры определяют, когда и как изменяется количество слотов.
Логика:

Плагин использует таймер для периодической проверки количества активных игроков.
Если количество игроков превышает IncreaseThreshold, количество слотов увеличивается на 10, но не более чем MaxPlayers.
Если количество игроков падает ниже DecreaseThreshold, количество слотов уменьшается на 10, но не менее чем на MinPlayers.
Уведомление игроков:

При изменении количества слотов игроки получают уведомление.(Можно убрать это)
