Простенький плагин написанный на Deep Seek. Выполняет команды определённый промежуток времени.
Основные функции плагина
Настраиваемый интервал выполнения команд

Администратор может задать интервал (в секундах), через который команды будут выполняться циклически.

Например:
```
3600 секунд = 1 час.

1800 секунд = 30 минут.
```
Выполнение команд при старте сервера

Если в конфигурации указать интервал 0, команды выполнятся один раз сразу после запуска сервера.

Гибкая конфигурация

Все настройки хранятся в файле HourlyCommands.json, который автоматически создается при первом запуске плагина.

Можно добавлять любые консольные команды, которые поддерживает сервер Rust (например, настройки сенти, времени взлома ящиков и т.д.).

Как работает плагин
Загрузка конфигурации

При старте сервера плагин читает файл HourlyCommands.json.

Если файла нет, создается конфиг с настройками по умолчанию:

```
{
  "IntervalSeconds": 3600,
  "Commands": [
    "sentry.interferenceradius 40",
    "sentry.maxinterference 12",
    "hackablelockedcrate.requiredhackseconds 500"
  ]
}
```
Запуск таймера

Если IntervalSeconds > 0, плагин запускает таймер, который выполняет команды через заданный интервал.

Если IntervalSeconds <= 0, команды выполняются сразу после загрузки плагина.

Выполнение команд

Каждая команда из списка Commands выполняется в консоли сервера с правами администратора.

Например:

```
sentry.interferenceradius 40  # Устанавливает радиус помех для сенти
hackablelockedcrate.requiredhackseconds 500  # Задает время взлома ящика
```
Логирование

Плагин выводит в консоль Oxide сообщения о выполненных командах:
```
[HourlyCommands] Executed: sentry.interferenceradius 40
```
