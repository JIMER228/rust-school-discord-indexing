Instructions for installing BetterNpc plugin:

1) Download the NpcSpawn.cs plugin (https://drive.google.com/drive/folders/1-18L-mG7yiGxR-PQYvd11VvXC2RQ4ZCu?usp=sharing)

2) Install the BetterNpc folder from the download into your server folder /oxide/data/

3) Install the NpcSpawn.cs plugin from the download into the folder /oxide/plugins/

4) Install the BetterNpc.cs plugin from the download into the folder /oxide/plugins/

IF YOU ALREADY HAVE ALL PLUGINS AND ARE JUST UPDATING
Follow the steps above by unloading each plugin and loading them as you get to their step
