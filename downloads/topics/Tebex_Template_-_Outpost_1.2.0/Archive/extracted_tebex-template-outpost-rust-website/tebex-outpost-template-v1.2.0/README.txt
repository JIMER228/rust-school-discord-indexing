INSTALLATION INSTRUCTIONS
=========================
***Be sure to open the template files in Visual Studio or similar code editing software. Copy/Paste from web browser has been know to cause missing code.***

1. Create a template. Go to Webstore > Appearance > Templates > Change and click Create Custom Template at the bottom
2. Enter the name of the template, in this case Promeus Rust. Select >Exo< as base template.
3. Click create and copy/paste the contents of the files in tebex-upload > template-files/Webstore into the respective files in the Webstore seciton of the Tebex dashboard.
4. "cms/page.html" is found in Webstore/cms/ of the template-files(folder/filename.html)
5. Scroll down to Assets, delete all pre-created asset files.
7. In Assets, click on Add -> CSS and upload the style.css located in template-files/Assets
7. In Assets, click on Add -> Image and upload the background.png located in template-files/Assets
8. Click on the uploaded image in the Assets list on Tebex. Rightclick the image and click Copy image URL
9. Click on layout.html in the file list, go to line 49 and replace [IMAGE_URL_HERE] with your image link
10. Click on the green arrow at the top right and select "Save And Publish"
10. Activate everything and enjoy your new theme!
