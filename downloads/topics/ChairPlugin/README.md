Описание плагина "ChairPlugin"
Этот плагин для игры Rust позволяет игрокам спавнить стул и садиться на него по команде.

Как это работает:

Когда игрок вводит команду /sit в чате, на его текущей позиции появляется стул.
Игрок может сесть на этот стул, чтобы отдохнуть.
Зачем это нужно?

Это добавляет элемент взаимодействия и позволяет игрокам делать паузу в игре, когда они устали.
