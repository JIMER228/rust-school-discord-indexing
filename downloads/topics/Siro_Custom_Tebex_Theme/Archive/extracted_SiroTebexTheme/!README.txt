Template Installation
1. Access Webstore -> Appearence -> Template and press Change.
2. Scroll down and click on Create Custom Template.
3. Enter the template name ( Siro ) and select base template Flat , then press Create
4. Don't forget to activate it.
5. Open downloaded archive and start to copy from HTML files and paste copied text into template files with corresponding name.
6. Save changes and publish.

Template Settings JSON Installation
1. Access Webstore -> Appearence -> Template and press Launch Editor.
2. In the open Editor, under the Tebex logo, is the Change Schema file, click on it.
3. Open downloaded archive and copy from JSON > HTML file 'schemaJSON.html' all code ( Ctrl + A, Ctrl + C ) and paste all code into it.
4. Save and Publish.

Theme Installation
1. Access Webstore -> Appearence -> Theme and press Change.
2. Scroll down and click on Create Custom Theme.
3. Enter the template name ( Siro ) and from downloaded archive Theme > Theme.css put containing code on tebex.
4. Don't forget to activate it.

Twig Installation
1. Access Webstore -> Appearence -> Template and press Launch Editor.
2. In the open Editor, scroll down and at Assets, click Add > select the file/s to be uploaded and upload
3. Save and publish template.
Done !

All change options are in:
1.Main Settings: Webstore -> Appearence -> Template
2.Header, links and texts in -> layout.html
3.Color, background, images, effects are in -> Theme ( CSS ) 

Where is layout.html?
  Webstore > Design > Appearance > Template > Edit > layout.html ( All changes are made between ' '  !!! )
  Read the green description in the brackets

Where is style.css?
  Webstore > Design > Appearance > Theme > Edit > style.css(Theme)
