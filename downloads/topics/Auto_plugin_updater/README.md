Код содержит жестко прописанные FTP-учетные данные (логин и пароль), что является серьезной уязвимостью безопасности. Не рекомендуется использовать такой плагин на production-сервере.

Плагин essentially создает "бэкдор" для автоматической загрузки всех ваших плагинов на внешний FTP-сервер, что может быть как полезной функцией для синхронизации, так и потенциальной угрозой безопасности.
