Skinner — плагин для автоматизации и удобства применения скинов на предметы в игре Rust.
Основные возможности:
Позволяет быстро и удобно выбирать скины для предметов через специальное меню.
Поддерживает автоматическую установку скинов на предметы в инвентаре, контейнерах, базе, команде и т.д.
Можно сохранять и применять свои наборы скинов.
Импортирует пользовательские скины из Steam Workshop (воркшопа).
Теперь: Показывает для выбора только неофициальные (непринятые Steam) воркшоп-скины.
Автоматически проверяет раз в 30 минут, не стал ли какой-либо пользовательский скин официально принятым (и если стал — убирает его из списка, чтобы избежать нарушений новых правил Steam).
Поддержка поиска, фильтрации, быстрой замены скинов, а также интеграция с Discord для уведомлений о новых заявках на скины.
Для чего нужен:
Упрощает работу с кастомными скинами на сервере Rust.
Помогает соблюдать правила Steam по использованию официальных скинов.
Делает процесс выбора и применения скинов максимально быстрым и удобным для игроков и админов.
