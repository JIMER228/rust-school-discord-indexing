Пользовательские выпадения предметов позволяют создавать 6 списков предметов, которые будут случайным образом выпадать в инвентаре игрока. Каждый список разделен в зависимости от действий, выполняемых игроком, таких как сбор, добыча, мародёрство, убийство животных, убийство NPC и убийство игроков. Каждый раз, когда игрок выполняет одно из этих действий, у него есть процентная вероятность (%) выпадения 1 предмета из соответствующего списка в его инвентаре. Опция VIP-участника позволяет VIP-игрокам получать более высокие шансы на выпадение предметов. Вы можете добавить в каждый список столько элементов, сколько захотите, используя краткое название элемента, пользовательское отображаемое название (необязательно), количество элементов, которое вы хотите сбросить, и идентификатор скина (необязательно).

6 пользовательских списков предметов для сбора, добычи, мародерства, убийства животных, убийства NPC, убийства игроков
Разрешение для каждого списка
Процент (%) вероятности выпадения случайного предмета из списка в инвентаре игрока
Опция VIP-процента (%) шансов для каждого списка
Возможность установить количество выпадающих для каждого товара
Возможность задать пользовательское имя для элементов (необязательно)
Возможность установить SkinID для элементов (необязательно)
Возможность включить / отключить определенные ресурсы для сбора списков мародерства
Возможность включить / отключить определенные объекты для списков убийств животных, NPC
