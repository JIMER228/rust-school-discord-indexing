Описание плагина "PoopPlugin"
Этот плагин для игры Rust добавляет забавный элемент в игровой процесс: каждые 5 минут из персонажа игрока будет выпадать конский навоз.

Как это работает:

Плагин автоматически запускается при старте сервера.
Каждые 5 минут он проверяет всех активных игроков.
Для каждого игрока в его текущем местоположении создается предмет — конский навоз.
