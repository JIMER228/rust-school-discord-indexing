Этот плагин для игры Rust добавляет элемент случайности и риска на сервер, реализуя концепцию русской рулетки.

Как это работает:

Каждые X минут (по умолчанию 5 минут) на сервере случайным образом выбирается один из активных игроков.
Выбранный игрок взрывается, и вокруг него создается эффект взрыва, после чего он погибает.
Зачем это нужно?

Это добавляет элемент неожиданности и напряжения в игру, заставляя игроков быть осторожнее и придавая игровому процессу больше динамики.
Настройка:

Интервал взрывов можно настроить в конфигурационном файле, что позволяет администраторам сервера изменять время по своему усмотрению.
