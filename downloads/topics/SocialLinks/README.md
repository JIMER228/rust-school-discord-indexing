**SocialLinks** – плагин для Rust, позволяющий владельцам серверов удобно делиться ссылками на социальные сети и другие ресурсы.

**📌 Функционал:**
* Список
* Отображение списка социальных сетей по команде /social
* Поддержка популярных платформ (Discord, VK, Telegram и др.)
* Возможность редактирования списка ссылок прямо в коде плагина
* Удобный и понятный вывод сообщений в чате
 

**🔧 Использование:**
1  Установите плагин в папку plugins.
2 Откройте файл плагина и отредактируйте ссылки на свои.
3 Перезагрузите сервер или выполните команду oxide.reload SocialLinks.

**Игроки могут использовать /social, чтобы увидеть список доступных ссылок.**

🏆 **Преимущества:**
✅ Простая установка и настройка
✅ Быстрый доступ к вашим сообществам
✅ Работает без дополнительных зависимостей

**Подключите игроков к вашему сообществу легко с SocialLinks!**
