Описание плагина "ExplosiveLootPlugin"
Этот плагин для игры Rust добавляет элемент неожиданности при лутании ящиков и ломании бочек.

Как это работает:

Когда игрок лутает ящик или ломает бочку, у него есть 5% шанс на взрыв.
Если происходит взрыв, игрок погибает, и вокруг него создается эффект взрыва.
Зачем это нужно?

Это добавляет элемент риска и напряжения в игру, заставляя игроков быть осторожнее при лутании.
Настройка:

Шанс взрыва можно настроить в конфигурационном файле, что позволяет изменить его по желанию администраторов сервера.
