If you are currently using one of this specific versions, please follow this steps to avoid config/data curruption.

If your old version is 1.x.x:
Delete all files from previous version (plugin, config, lang).
Install the plugin.

If your old version is 2.0.0 or 2.0.1 (custom):
Install 2.0.2 version.
Install 2.0.3 version.

If you already have 2.0.3 (custom):
Remove old lang files.
Install 2.0.3 version from this archive.
